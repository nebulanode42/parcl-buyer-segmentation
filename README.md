# Parcl Real Estate Buyer Segmentation & Market Intelligence

An end-to-end machine learning system and interactive Streamlit web dashboard for customer segmentation and investment profiling in real estate markets.

## Features
- **Data Preprocessing & Hygiene**: Merged client demographics with transaction history, automated age calculation, and continuous feature scaling.
- **Clustering Pipeline**: Unsupervised behavioral profiling with K-Means and Agglomerative Hierarchical clustering.
- **Interactive Analytics**: 4-module Streamlit dashboard covering segment distribution, investor behaviors, regional analysis, and descriptive metrics.
